PROJECT 02

Breast Cancer Neural Network Classification

A machine learning classification project using a multilayer perceptron neural network to classify breast tumors as malignant or benign based on diagnostic measurements.

OVERVIEW

Project Overview

The objective of this project was to build and evaluate a neural network classification model capable of identifying whether a breast tumor is malignant or benign.

The project focused not only on prediction performance, but also on understanding neural network architecture, preprocessing requirements, model training, and optimization.

PROBLEM

Classification Problem

Diagnostic measurements describing characteristics of cell nuclei are used as input features. The neural network learns patterns within these measurements to classify each observation into one of two diagnostic categories.

DATA PREPROCESSING

Preparing the Data

Before training the neural network, the dataset was prepared to ensure that the model received appropriate numerical inputs.

Remove ID Feature Target Encoding Train-Test Split Feature Scaling

MODEL

Neural Network Architecture

A Multilayer Perceptron classifier was used to learn nonlinear relationships between the diagnostic features and the target diagnosis.

Different hidden-layer configurations and neuron counts were explored to evaluate whether changes in network complexity improved classification performance.

Input Layer Hidden Layers Output Classification Backpropagation

MODEL EVALUATION

Evaluating Performance

Model performance was evaluated using several classification metrics to understand both overall prediction accuracy and the types of classification errors made by the neural network.

Accuracy Confusion Matrix Precision Recall F1-Score Classification Report

RESULTS

Model Performance

Optimizing the neural network architecture improved classification performance on the held-out test set. The optimized model achieved 98.25% accuracy compared with 97.37% for the baseline network.

OPTIMIZATION

Architecture Optimization

Several neural network architectures were evaluated using GridSearchCV with 5-fold cross-validation.

The baseline network contained one hidden layer with 30 neurons. The best-performing configuration used two hidden layers with 100 and 50 neurons.

Baseline: 30 neurons

One hidden layer produced 97.37% test accuracy.

Optimized: 100 → 50 neurons

Two hidden layers increased test accuracy to 98.25%.

Fewer malignant cases missed

The baseline model misclassified 3 malignant cases as benign, while the optimized network reduced this number to 2.

VISUALIZATIONS

Model Analysis

Baseline Confusion Matrix

The baseline model correctly classified all 72 benign cases and 39 of 42 malignant cases.

Optimized Confusion Matrix

KEY TAKEAWAYS

What I Learned

Scaling matters for neural networks

Standardizing features helps neural networks train more effectively when input variables have different scales.

Architecture affects performance

Changing hidden layers and neurons can influence both predictive performance and model complexity.

Accuracy alone is not enough

The confusion matrix, precision, recall, and F1-score provide a more complete view of classification quality.

Training loss provides useful information

The loss curve helps visualize whether the neural network is successfully learning during training.
