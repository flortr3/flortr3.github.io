BUSINESS PROBLEM

Problem

A mobile phone company wants to better understand how product specifications influence price positioning. A predictive model can help estimate the appropriate market price category for new devices based on their technical features.

DATA

Dataset

The dataset contains multiple technical features describing mobile phones, including battery power, RAM, internal memory, screen dimensions, camera specifications, connectivity features, and processor characteristics. The target variable represents four mobile phone price ranges.

METHODOLOGY

Approach

The project included data exploration, preprocessing, feature analysis, model training, model evaluation, and comparison between classification approaches.

Data Exploration Data Preprocessing Feature Analysis Classification Model Evaluation Hyperparameter Optimization

TOOLS

Technologies Used

Python Pandas NumPy Scikit-learn Matplotlib Jupyter Notebook

RESULTS

Key Results

The classification models demonstrated that mobile phone specifications can be used effectively to predict price categories. Model comparison and optimization helped identify the strongest approach for this dataset.

KEY TAKEAWAYS

What I Learned

This project strengthened my understanding of classification, model comparison, hyperparameter tuning, data preprocessing, and the importance of connecting machine learning results with a real business problem.
